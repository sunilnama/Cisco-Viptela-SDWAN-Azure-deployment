Use draw.io MCP to create a workflow diagram for Versa BGP up/down automation.

Flow requirements:
1. Monitor BGP neighbor status
2. Detect up/down event
3. Send event to automation engine
4. Fetch device, peer, VRF, and site details
5. Check whether event is DOWN or UP

DOWN branch:
- Validate outage persistence
- Run health checks
- Check interface state
- Check underlay reachability
- Check routing policy/session logs
- Generate alert
- Open or update incident ticket
- Notify NOC / Ops team
- Log remediation recommendation

UP branch:
- Confirm session is stable
- Verify route learning/restoration
- Clear or downgrade alert
- Update incident ticket
- Notify stakeholders
- Log recovery confirmation

Final step:
- Store audit trail and close workflow

Format:
- left-to-right
- decision diamond for UP/DOWN
- process boxes for actions
- clear labels
- professional operations workflow
